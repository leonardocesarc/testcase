🧪 Test Cases – Official Repository
📌 Overview

This repository contains all files, spreadsheets, and documents used in the research experiment entitled:

“Investigating the Use of Large Language Models (LLMs) in the Elaboration of Test Cases.”

The main goal is to ensure transparency, reproducibility, and usability of the experimental artifacts, enabling other researchers to replicate and extend the study.

🎯 Project Objective

The repository aims to:

Centralize all materials used in the study
Provide datasets and artifacts for experiment replication
Support further research on LLM-based test case generation

📁 Repository Structure

📊 Spreadsheets

Calculation Spreadsheet.xlsx

Oracle_HU_Analysis_Spreadsheet.xlsx

▶️ How to Use

Open the spreadsheets to explore the experimental data and calculations.
Review the prompt documents to understand how test cases were generated.
Follow the methodology described in the associated paper to replicate the study.

📚 Glossary

LLM (Large Language Model):
An AI model trained on large datasets capable of generating natural language text.

Test Case:
A set of conditions or variables used to verify software functionality.

User Story (HU):
A short description of a system feature from the user’s perspective.

Zero-shot Prompting:
A technique where the model performs a task without prior examples.

One-shot Prompting:
A technique where the model is given a single example before performing the task.

🔁 Reproducibility

All artifacts provided in this repository were used in the experiment and are sufficient to support replication when combined with the methodology described in the paper.
